# 🤖 AI Hallucination Detector

An AI-powered web application that analyzes AI-generated answers, identifies potentially unreliable claims, and helps users verify factual information using evidence sources.

## ✨ Features

- 🤖 AI-generated text analysis
- 🔍 Automatic claim identification
- 📊 Hallucination risk scoring
- 🌐 Evidence source search
- ✅ Claim verification support
- 🎨 Clean and responsive web interface

## 🛠️ Tech Stack

- Python
- Flask
- HTML
- CSS
- REST API
