# 🤖 AI Hallucination Detector

A web-based system that analyzes AI-generated text, identifies factual claims, and helps users verify those claims using external evidence sources.

## ✨ Features

- AI-generated text analysis
- Automatic claim identification
- Hallucination risk scoring
- Evidence source search
- Claim verification support
- Clean and responsive web interface

## 🛠️ Tech Stack

- Python
- Flask
- HTML
- CSS
- REST API
